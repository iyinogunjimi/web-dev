My Recent Work

Here Are Some Of My Recent Solo Projects

Full-Stack E-commerce Website with Paystack Checkout

A responsive e-commerce site built for a footwear brand, targeting the Nigerian market. Built with a React frontend and a Node.js/Express backend, with Paystack integrated for payment processing.

Github Live Demo

Web Application Testing

Manual penetration testing practice against intentionally vulnerable web applications (DVWA, OWASP Juice Shop) to identify and exploit common flaws such as SQL injection, XSS, and broken authentication, following the OWASP Top 10 methodology.

Github Live Demo

Network Traffic Analysis

Built a cybersecurity home lab using VirtualBox with a Wazuh SIEM deployment and a Splunk Enterprise instance ingesting real firewall logs via a Universal Forwarder. Used Wireshark for packet-level traffic inspection and practiced log analysis with SPL and KQL, mapping findings to the MITRE ATT&CK framework.

Github Live Demo

Vulnerability Assessment

Ran vulnerability scans against lab machines using Nessus to identify misconfigurations and unpatched services, then prioritized findings by CVSS severity and documented remediation steps in a written report.
